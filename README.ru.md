# LAMPOCHKA

![LAMPOCHKA](screen/LAMPOCHKA_cover.png)

*English documentation: [README.md](README.md)*

Аддон Blender для управления всеми источниками света сцены из одной панели — плюс браузер HDRI-окружений.

**Blender 4.2+ · Автор: Maksim Kovalev**

---

Вместо поиска светильников в аутлайнере и переключения между объектами — отдельная панель с мгновенным доступом к настройкам каждого источника: цвет, мощность, тени, параметры по типу, трансформы.

## Возможности

### Список источников света
- Все светильники сцены с иконками типов (Point / Sun / Spot / Area)
- Фильтр по имени
- Клик — выбор во вьюпорте
- Шестерёнка (⚙) — инлайн-настройки

### Управление видимостью
- 👁 — видимость во вьюпорте по светильнику
- 📷 — видимость на рендере по светильнику
- 🗑 — удалить светильник прямо из строки (дружелюбно к Ctrl+Z)
- Глобальные тумблеры «вся видимость / весь рендер» в шапке

### Инлайн-настройки (через ⚙)
- Тип, цвет, мощность
- **Температура Кельвина (v2.3)** — тумблер ведёт цвет света от температуры чёрного тела (слайдер 1500–12000 K); исходный цвет запоминается и восстанавливается при выключении. Нодовые светильники (например, с IES-профилем) ведутся через ноду Blackbody. Работает в Cycles и EEVEE
- Тени + размер тени
- **Point** — радиус
- **Sun** — угол
- **Spot** — размер, blend, показ конуса
- **Area** — форма, размер X/Y
- **Cycles** — ноды, сила эмиссии
- Контактные тени (дистанция, bias, толщина)
- Объём (volume factor)
- Трансформы (свёрнуто по умолчанию): локация, ротация, скейл

### Управление светильниками
- Добавление света (Point / Sun / Spot / Area) из меню шапки
- Дублирование / удаление в настройках
- Перемещение вверх/вниз по списку

### Синхронизация со вьюпортом
- Выбор светильника во вьюпорте подсвечивает его в панели
- Выбор в панели выбирает светильник во вьюпорте
- Состояние настроек переносится между светильниками:
  - Настройки были открыты → откроются для нового света
  - Настройки были закрыты → останутся закрытыми

### HDRI-браузер (v2.1)
- Свёртываемая суб-панель **HDRI** под списком светильников
- Укажи папку — все `.exr` / `.hdr` появляются сеткой превью
- **Карусель превью (v2.4)** — компактный ряд из трёх карточек (предыдущая / активная / следующая) с крупными превью; листай стрелками, клик по карточке применяет сразу
- **Стрелки prev/next (v2.4)** — листание папки с мгновенным применением каждого HDRI
- **Apply HDRI** — строит нодовую цепочку мира (TexCoord → Mapping → Environment → Background) одним кликом
- Если в мире уже есть окружение — меняется только картинка, ноды не разрушаются
- **Hide from Camera (v2.4)** — камере показывается плоский цвет (по умолчанию чёрный), а освещение и отражения остаются от HDRI; классический VFX-приём для рендера на чистой болванке
- **Clear HDRI** — сносит HDRI-цепочку и оставляет чёрный Background с нулевой силой (без света окружения); ротация сбрасывается, панельная Strength возвращается к дефолтной 1 — следующий HDRI применится на полной мощности
- **Ротация** — вращение окружения (Z для турнтейбл-спина, X/Y для наклона)
- **Strength** — интенсивность окружения, живое обновление
- **Rotate: Shift+RMB** — тумблер; когда включён, драг **Shift + ПКМ** во вьюпорте крутит HDRI вокруг Z. Ctrl+Z отменяет весь драг. Тумблер всегда выключен в свежей сессии (сбрасывается при каждой загрузке файла), чтобы дефолтная навигация не перехватывалась неожиданно
- Ротация и сила применяются к нодовой цепочке даже после применения другого HDRI
- **Запоминание папки** — последняя выбранная HDRI-папка хранится в настройках аддона и автоподставляется в каждом новом проекте; отдельный `.blend` может переопределить её своей папкой
- **Авто-ремонт папок (v3.3)** — если сохранённая папка исчезла с диска (библиотеку переехали или удалили), при загрузке файла она чинится из настроек аддона, затем из библиотеки, встроенной в team-сборку. Тот же ремонт срабатывает при правке папки в настройках. Неисправимый путь панель показывает как «Folder not found: …» вместо вводящего в заблуждение «нет файлов»; касается всех браузеров — HDRI, IES, Gobo и Presets

#### Где хранится запомненная папка?
`Preferences → Add-ons / Get Extensions → LAMPOCHKA → Default HDRI Folder`.
Выбор папки в панели обновляет её автоматически; можно править и вручную.

### Солнце (v2.5)
- Свёртываемая суб-панель **Sun**: наведение любого солнечного света по времени суток, дате и локации
- Время / дата / широта / долгота / UTC-сдвиг / сдвиг севера / дистанция
- Пресеты: **Noon** (полдень), **Golden Hour** (час до заката), **Sunset** (закат)
- Вывод высоты, азимута, времени восхода и заката
- **Анимация дня**: поставь кейфрейм на *Time* — солнце следует за каждым кадром (пауза на рендерах/запеканиях)
- Положение солнца считается по алгоритму NOAA (public domain)

### IES-браузер (v2.3)
- Свёртываемая суб-панель **IES** под списком светильников
- Укажи папку — все `.ies` появляются сеткой (превью подхватываются из подпапки `thumbnails/`, если есть: `thumbnails/<имя>.jpg`)
- **Apply IES** — строит IES-сетап на **активном светильнике** (Point или Spot): `IES → Emission → Output`
- Если на светильнике уже есть IES-сетап LAMPOCHKA — меняется только файл; если есть Emission-цепочка — IES-нода вставляется без разрушения нод
- **Remove IES** снимает IES-ноду с активного светильника
- **Настройки IES per-light**: **Power** (множитель яркости профиля) и **Mix** (0–100%: насколько профиль формирует свет против равномерного); пресеты сохраняют и восстанавливают оба
- IES-профили работают **только в Cycles** (панель предупреждает при другом движке)
- Последняя папка запоминается в настройках, как и HDRI

### Пресеты световых сетапов
- Свёртываемая суб-панель **Presets**: сетапы живут как `.blend`-пакеты и применяются аппендом setup-коллекции — empty-иерархии, нодовые деревья и мировые трансформы приезжают ровно в авторском виде
- **Install from Zip** — установка одного или нескольких пакетов пресетов из `.zip`-архивов; каждый zip становится подпапкой папки пресетов. PLS-совместимая структура (`library/*.blend` + `library/thumbs/`) разворачивается автоматически
- Укажи папку пресетов — каждая коллекция каждого `.blend` в папке (рекурсивно) появляется в сетке как сетап; опциональные превью из `thumbs/<имя>.png` или `thumbnails/<имя>.png` рядом с пакетом
- **Save Setup** — записывает светильники сцены (вместе с родительскими empty и поддеревьями ригов) как `.blend`-сетап в папку пресетов. Давай светильникам осмысленные имена (Key, Rim, Fill) — сетап читается как световая схема
- **Карусель** — ряд карточек с превью (предыдущий / активный / следующий) со стрелками ◀ ▶, как в HDRI-браузере; **переключение пресетов применяет их сразу**, без отдельной кнопки Apply. Клик по соседней карточке перескакивает на неё; каталог зациклен
- **Solo Light** — кнопка SOLO в строке светильника изолирует его: остальные скрываются (вьюпорт + рендер), пока соло не снято или не перенесено на другой свет
- **Cycle Select** — ◀ ▶ в шапке списка перебирают светильники сцены без прокрутки списка
- **Flip Preset** — Flip X / Flip Y зеркалят применённый риг пресета относительно осей корня (двойной флип возвращает как было)
- **Общая интенсивность** — один слайдер масштабирует энергию всех светов применённого пресета относительно авторских значений (без накопления при повторных применениях)
- **Поворот пустышки по Z** — вращение применённого пресета вокруг его родительской пустышки по мировой оси Z; возврат слайдера на ноль восстанавливает авторскую ориентацию
- **Избранное** — помечай сетапы сердечком ♥ рядом с именем; переключатель-сердце в шапке панели включает режим «только избранные» в карусели (хранится в настройках, переживает переезд библиотеки)
- **Apply** — переприменяет выбранный сетап по требованию
- **Clear Lights** — удаляет все объекты, пришедшие из пресетов LAMPOCHKA
- **Preferences → Installed Preset Packages** — список установленных пакетов со счётчиком blend'ов и кнопкой удаления у каждого, плюс *Remove All Packages* (с подтверждением). Только в Preferences — для сайдбара слишком опасно
- Неразрешённые текстуры (пакет установлен без своей папки `textures/`) честно репортятся при применении, а не молча пропускаются

### Интерактивная расстановка (v3)
- **Кнопка-курсор** в строке светильника — мастер-выключатель, только вручную:
  - **ВКЛ** — свет свободно движется за курсором (без привязки), навигация вьюпорта работает
  - **Alt** (зажат) — привязка света к поверхности под курсором
  - **G** — работает как оператор расстановки, пока кнопка нажата: применяет текущий прогон, повторное нажатие ставит снова; при отжатой кнопке G — нативный Grab
  - **ЛКМ / Enter** — применить текущий прогон, **ПКМ / Esc** — откатить прогон в стартовую точку
  - **Колесо** — мощность, **Shift + колесо** — размер, **Ctrl + колесо** — глубина плоскости движения
  - **ВЫКЛ** — всё возвращается в норму, ничего не работает
- Состояние кнопки сбрасывается при загрузке файла, чтобы режим не активировался неожиданно

### Light & Shadow Linking (v3)
- **Light Linking: Pick** / **Shadow Linking: Pick** в ⚙-настройках светильника (Blender 4.x/5.x)
- Кликай объекты во вьюпорте, чтобы линковать/разлинковывать их как ресиверы или блокеры света — быстрее, чем копаться в коллекциях аутлайнера
- Enter — принять, Esc / ПКМ — откат к состоянию до сессии линковки
- Кнопки Clear Receivers / Clear Blockers очищают назначения

### Гобо-проекции (v3)
- Свёртываемая суб-панель **Gobo**: проекция текстуры из активного **спота** (Cycles)
- Укажи папку — текстуры появляются сеткой превью, Apply применяет
- Работает с **любым активным светильником**: спот — классическая конусная проекция, площадка — плоский «рисунком-скоубокс», point при Apply автоматически превращается в спот (Sun отказывается — нет позиции, нет проекции)
- Строится на **активном светильнике**: если нод нет — строится чистая цепочка `TexCoord → Mapping → Image → Emission → Output`; если Emission-цепочка есть — гобо вплетается умножением без разрушения нод
- **Настройки проекции на каждом светильнике** (хранятся на свете — каждый гобо независим):
  **Rotation**, **Scale X / Y** (растянуть паттерн в жалюзи/полосы), **Offset X / Y**,
  **Mix** (0–100%: гобо как акцент поверх основного света), **Invert** и **Flip X**
- Пресеты сохраняют гобо-текстуру и нодовую цепочку (ручки гобо per-light сбрасываются в дефолт при применении)
- **Remove Gobo** снимает гобо-ноды и восстанавливает прежний источник цвета
- Последняя папка запоминается в настройках, как у HDRI и IES

## Установка

`lampochka_extension.zip` приложен к [последнему релизу](https://github.com/abyrvalg379/LAMPOCHKA/releases/latest).

1. `Edit → Preferences → Get Extensions`
2. ⚙ → `Install from Disk...`
3. Выбери `lampochka_extension.zip`

## Использование

`View3D → Sidebar (N) → LAMPOCHKA`
